# X 清流 · X Jev Filter

**让时间线更清爽的 Chrome 扩展。** 自选广告类别，使用 Jev 过滤营销推文和回复，并可选择过滤疑似 AI 创作文字。

**简体中文** | [English](README.en.md)

> 当前版本：0.4.1 · Manifest V3 · 自用原型。模型结果可能误判，尚未进行真实 X 页面、真实 Jev API 的完整验收或准确率评测。

[更新日志 / Changelog](CHANGELOG.md) · [v0.4.1 Release](https://github.com/Li-Chuangqi/x-jev-filter/releases/tag/v0.4.1)

## 功能

- **按类别过滤**：系统广告、商品推广、付费服务与课程、返佣与邀请推广、商业引流、投资与虚拟币营销、博彩推广、成人服务广告。
- **疑似 AI 创作识别**：独立于广告分类，默认关闭；只分析文字，无法证明真实作者身份。
- **显性屏蔽规则**：账号、内容条件和 Jev 语义规则可编辑、停用及导入导出。
- **可恢复的折叠提示**：显示过滤原因并提供“显示原文”；也可关闭提示，直接隐藏内容。
- **账号白名单**：跳过过滤，不把该账号的文字发送给模型。
- **成本控制**：内容缓存、请求冷却、跨标签页共享每日上限；API 出错时正常显示。
- **无需后端或构建**：原生 JavaScript，扩展运行时没有 npm 依赖。

## 安装

可直接下载 [v0.4.1 安装包](https://github.com/Li-Chuangqi/x-jev-filter/releases/download/v0.4.1/x-jev-filter-0.4.1.zip)，解压后选择包含 `manifest.json` 的目录加载。**从 v0.3.x 升级前先导出规则，新扩展 ID 可能导致旧数据无法自动继承。**

1. 点击仓库 **Code → Download ZIP**，解压到固定目录；或克隆仓库。
2. Chrome 打开 `chrome://extensions`，开启**开发者模式**。
3. 点击**加载已解压的扩展程序**，选择项目内的 **`extension/` 文件夹**，不是项目根目录。
4. 刷新 X 页面，点击插件图标进入设置。
5. 如需 Jev，在 [TypeSafe 控制台](https://console.typesafe.ai/) 创建密钥，在“连接 Jev”中填写并测试，再开启“用 Jev 识别营销内容”。
6. 勾选希望屏蔽的类别，点击**保存设置**。

更新：替换原目录文件，在扩展管理页点击重新加载，再刷新 X 和设置页。不要将密钥填进代码或提交至 GitHub。

## 默认设置与过滤规则

| 设置 | 默认值 |
| --- | --- |
| 启用清流 | 开启 |
| 系统广告（X 平台投放广告） | **关闭** |
| Jev 识别 | **关闭**，需配置密钥并主动启用 |
| 疑似 AI 创作内容 | **关闭** |
| AI 广告类别 | 全选，仅在 Jev 开启后生效 |
| 显示折叠提示 | 开启 |
| 折叠阈值 | 0.95，模型估计，不等于准确率 |
| 限制每日 API 请求量 | 开启，每日 1000 次；可在高级设置关闭，所有 X 标签页共享 |

系统广告在本地根据页面标记判断；取消该选项后，识别出的系统广告也不再经过 AI 过滤。AI 广告类别多选时，命中任一类别即可过滤，类别可能重叠。疑似 AI 创作文字使用单独判断，可在所有广告类别取消后独立工作，但仍需开启 Jev 总开关。

自动 API 判断仅处理当前可见标签页中屏幕内的推文文字；本地规则也会应用到已加载内容。每条请求最多 5000 字符；最多缓存 500 条结果，24 小时过期，退出浏览器后清空。每分钟最多 120 次请求，12 秒超时。失败请求和手动连接测试计入本地请求预算；额度限制不是美元消费上限。在「连接 Jev → 高级设置」关闭「限制每日 API 请求量」后，不设每日总量上限，用量统计、每分钟限流及错误冷却继续生效。更新会保留已有上限，重新开启会使用先前保存的数值。

## 个人跨设备同步（v0.4.0）

在每台设备登录同一 Chrome 账号并启用浏览器的扩展程序同步，在清流设置中开启“通过 Chrome 同步我的规则”。首次开启会合并规则；之后新增、编辑、启停和删除自动同步，也可点击“立即同步”。需要各设备安装相同扩展 ID 的版本。

- 默认关闭，仅同步规则及其规则内例外。规则名称、模板和条件可能包含推文文字或账号，开启即同意将它们交给 Chrome 同步存储。
- 规则同步不上传 API 密钥、独立来源样本、全局白名单、过滤偏好或用量；不共享给其他用户。不需要 X 登录授权，也不会按 X 账号隔离规则。
- 本地优先，断网可继续使用；Chrome 恢复同步后传输数据。插件只能报告同步存储合并结果，不能确认云端送达或 Chrome 账号登录状态。
- 并发编辑以版本时间较新者为准，相同时按设备标识确定；被替换的本机规则最多保存 20 条冲突备份，可导出后通过规则管理导入恢复（导入默认停用）。建议设备系统时间保持准确。
- 删除采用长期保留的删除标记，防止旧设备恢复已删除规则。Chrome 限额为总计 100 KB、单项 8 KB、512 项，删除标记也占容量。超限时保留本地数据并显示错误，不悄悄丢弃规则；规则较多时使用 JSON 导入导出。
- 关闭开关仅停止本设备同步，不清除云端规则。请勿在共用 Chrome 配置中切换不同人的账号来共享此功能；使用独立 Chrome 配置。

**从 v0.3.x 升级：先在旧插件导出规则，再安装新版本。** 为使解压安装在各设备拥有相同 ID，v0.4.0 引入固定公开标识，ID 为 `hbcocdmomlljjgphneaeefolcondcnll`。旧解压版可能被 Chrome 视为另一个插件，不能自动继承其数据。导出后停用旧版，在新版导入规则并按需启用；重新设置过滤偏好及密钥。其他设备安装相同版本后开启同步即可，无需反复导入。不要同时运行两个清流插件。

这不是 Chrome Web Store 发布签名；以后若上架商店，需使用商店指定的扩展标识并另行安排迁移。真实 Chrome 账号的两台设备传输仍需用户环境验收。

## 可选的 Jev 密钥同步（v0.4.1）

“Jev 密钥同步”独立于规则同步，默认关闭。第一台设备先在“连接 Jev”保存 API Key，再打开密钥同步开关、设置至少 12 字符的独立同步口令并点击“开启并解锁”。其他设备使用同一 Chrome 账号和扩展 ID，打开相同开关、输入一次该口令，即可解密已有密钥，无需重新粘贴 Key。

- 使用 Web Crypto PBKDF2-SHA-256（600,000 次）派生 AES-256-GCM 密钥，随机盐和每次独立随机 IV。Chrome 同步存储只接收盐、IV、算法参数和密文，不接收明文 API Key 或口令。
- 设备本地 IndexedDB 保留不可导出的 CryptoKey，因此同一设备重启浏览器后可以恢复密钥。它仍依赖设备与浏览器配置的安全，不能防御已控制该浏览器的恶意程序。
- 开启后，在“连接 Jev”保存新 Key 会更新同步密文；其他已解锁设备收到后应用。容量或写入失败时保留原密钥并提示，输入的新 Key 不视为保存成功。
- 关闭密钥同步会移除本设备解锁凭据，当前会话中的 Key 保留到退出或清除。点击“清除密钥”同时关闭本设备密钥同步，避免自动恢复。两者都不删除云端密文或其他设备的密钥。
- 不自动开启 Jev 内容识别；每台设备仍独立选择识别功能。妥善保管独立同步口令，插件不提供找回；错误口令或损坏密文不会覆盖现有本机密钥。
- 已通过真实 Chrome 的 Web Crypto / IndexedDB 持久化检查；实际 Google 账号下双设备传输仍待验收。

## 显性、可编辑的屏蔽规则

评论及推文操作栏的划线眼睛按钮在悬停时显示，位于分享按钮左侧；点击直接屏蔽并学习，不再显示选择菜单：

- **屏蔽并学习相似内容**：点击后直接折叠，不弹出编辑框、确认或浮动通知。自动保存可靠的本地条件；无法提取可靠条件时保存原帖规则与样本，不扩大屏蔽范围。可在折叠条撤销，或到设置中编辑。保存失败仅在折叠条提示，本条仍临时折叠。

设置页中的“屏蔽规则”支持新建、查看来源、编辑、启用/停用、删除、查找及 JSON 导入导出。折叠提示展示命中的规则名称，支持显示原文或撤销规则。

| 类型 | 可编辑内容 | 执行方式 |
| --- | --- | --- |
| 账号规则 | @账号、例外账号和关键词 | 本地精确匹配 |
| 内容规则 | 正文/昵称/两者、关键词、链接域名、全部/任一条件，或相似文字模板 | 本地匹配 |
| 语义规则 | 具体内容模式、匹配范围、应保留的语义例外 | Jev 独立判断每条规则 |

- 关键词按包含文字匹配，不区分英文大小写。域名精确匹配文字中可见的 HTTP(S) URL，不自动展开短链接或包含子域名。相似文字模板至少 20 字符，只匹配长度接近、文字高度近似的内容。
- 点击学习后，完整的本地条件会直接保存为规则。短评论无法形成可靠模板时仅保存原帖规则与样本，后续可在设置中编辑。本版本不自动生成自然语言规则，不做模型训练或微调。
- 每条规则的例外关键词/账号优先于该条匹配；其他规则仍独立判断。全局白名单优先于所有规则。
- **语义规则默认关闭**，需开启“连接 Jev”总开关及“用 Jev 执行语义规则”。发送当前文字、昵称、所有适用的已启用语义规则描述与例外，以及最多 5 条相关来源样本文字和昵称。每条规则使用独立 Noul 问题；至少 0.98 的模型估计才折叠，分值不等于准确率。停用规则、编辑条件或修改样本会使相关判断重新评估。
- **保存的规则长期保留，不再按 100 条淘汰**。只有独立来源样本限制为 100 条，重复样本合并，满额时淘汰最旧样本。删除或淘汰来源样本不删除规则，其中已保存的模板和描述仍保留。超出浏览器存储容量会报错，不会静默删除规则。
- 导入合并到现有规则，全部默认停用，检查后再启用。导出含规则条件、账号及模板文字，不含独立样本记录、密钥或用量。每次导入文件最多 2 MB。
- 升级自动将旧账号、原帖及相似记录迁移为可编辑规则，并保留原设置的开关意图；旧版已被淘汰的记录无法恢复。旧“仅本条”规则保留为指定原帖规则。

## 隐私与密钥

启用 Jev 后，可见推文正文与引用文字会发往 **TypeSafe**，可能包含受保护账号内容及正文中的个人信息。不读取私信，除主动开启上述 Jev 语义规则时发送昵称、规则与参考样本外，不主动发送账号标识、推文 URL、Cookie、图片或视频；若这些信息出现在正文中，则随正文发送。

- 默认仅在 `chrome.storage.session` 保存明文密钥，内容脚本无法读取。独立开启密钥同步后，密文进入 Chrome 同步存储；设备在 IndexedDB 保存不可导出的解锁 CryptoKey，重启后恢复到会话存储。同步口令不保存、不上传。
- 设置与用量存于本地；哈希判断缓存存于会话内存。不内置遥测。规则与来源样本另存于本地，可能包含文字、昵称、账号和推文 ID。规则保留直到主动删除；独立样本可主动删除或被样本容量淘汰。
- TypeSafe 的服务端数据处理以其[隐私政策](https://typesafe.ai/legal/privacy-policy)为准。

接口固定为 `https://api.typesafe.ai/v1/systemone`，模型为 `jev-latest`，使用原生 `state + questions` / `noul` 接口，不是聊天补全接口。参考 [TypeSafe API 文档](https://docs.typesafe.ai/api)。

## 局限

X 页面改版可能导致漏判；模型返回前内容会短暂显示。仅支持文字，未做图片 OCR、视频识别或完整对话上下文分析。模型可能误判广告，也无法可靠鉴定 AI 作者身份。`jev-latest` 更新后表现可能变化。

**56 项模拟测试通过**，覆盖 DOM 节点复用、类别切换、缓存、限流、失败时保留内容和恢复原文等逻辑。这不代表真实页面兼容性或模型准确率。尚未上架 Chrome Web Store。本项目与 X、TypeSafe 无官方关联。
