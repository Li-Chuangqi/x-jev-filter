# X 清流 · X Jev Filter

**让时间线更清爽的 Chrome 扩展。** 自选广告类别，使用 Jev 过滤营销推文和回复，并可选择过滤疑似 AI 创作文字。

**简体中文** | [English](README.en.md)

> 当前版本：0.1.5 · Manifest V3 · 自用原型。模型结果可能误判，尚未进行真实 X 页面、真实 Jev API 的完整验收或准确率评测。

## 功能

- **按类别过滤**：系统广告、商品推广、付费服务与课程、返佣与邀请推广、商业引流、投资与虚拟币营销、博彩推广、成人服务广告。
- **疑似 AI 创作识别**：独立于广告分类，默认关闭；只分析文字，无法证明真实作者身份。
- **可恢复的折叠提示**：显示过滤原因并提供“显示原文”；也可关闭提示，直接隐藏内容。
- **账号白名单**：跳过过滤，不把该账号的文字发送给模型。
- **成本控制**：内容缓存、请求冷却、跨标签页共享每日上限；API 出错时正常显示。
- **无需后端或构建**：原生 JavaScript，扩展运行时没有 npm 依赖。

## 安装

1. 点击仓库 **Code → Download ZIP**，解压到固定目录；或克隆仓库。
2. Chrome 打开 `chrome://extensions`，开启**开发者模式**。
3. 点击**加载已解压的扩展程序**，选择项目内的 **`extension/` 文件夹**，不是项目根目录。
4. 刷新 X 页面，点击插件图标进入设置。
5. 如需 Jev，在 [TypeSafe 控制台](https://console.typesafe.ai/) 创建密钥，在“连接 Jev”中填写并测试，再开启“用 Jev 识别营销内容”。
6. 勾选希望屏蔽的类别，点击**保存设置**。

更新：替换原目录文件，在扩展管理页点击重新加载，再刷新 X 和设置页。不要将密钥填进代码或提交至 GitHub。

## 默认设置与过滤规则

| 设置 | 默认值 |
| --- | --- |
| 启用清流 | 开启 |
| 系统广告（X 平台投放广告） | **关闭** |
| Jev 识别 | **关闭**，需配置密钥并主动启用 |
| 疑似 AI 创作内容 | **关闭** |
| AI 广告类别 | 全选，仅在 Jev 开启后生效 |
| 显示折叠提示 | 开启 |
| 折叠阈值 | 0.95，模型估计，不等于准确率 |
| 每日请求上限 | 1000，所有 X 标签页共享 |

系统广告在本地根据页面标记判断；取消该选项后，识别出的系统广告也不再经过 AI 过滤。AI 广告类别多选时，命中任一类别即可过滤，类别可能重叠。疑似 AI 创作文字使用单独判断，可在所有广告类别取消后独立工作，但仍需开启 Jev 总开关。

仅处理当前可见标签页中屏幕内的推文文字。每条请求最多 5000 字符；最多缓存 500 条结果，24 小时过期，退出浏览器后清空。每分钟最多 120 次请求，12 秒超时。失败请求和手动连接测试计入本地请求预算；额度限制不是美元消费上限。

## 隐私与密钥

启用 Jev 后，可见推文正文与引用文字会发往 **TypeSafe**，可能包含受保护账号内容及正文中的个人信息。不读取私信，不主动发送作者字段、推文 URL、Cookie、图片或视频；若这些信息出现在正文中，则随正文发送。

- 密钥仅存于 `chrome.storage.session`，内容脚本无法读取；退出浏览器后需重新输入。
- 设置与用量存于本地；哈希判断缓存存于会话内存。不内置遥测，不记录原始推文日志。
- TypeSafe 的服务端数据处理以其[隐私政策](https://typesafe.ai/legal/privacy-policy)为准。

接口固定为 `https://api.typesafe.ai/v1/systemone`，模型为 `jev-latest`，使用原生 `state + questions` / `noul` 接口，不是聊天补全接口。参考 [TypeSafe API 文档](https://docs.typesafe.ai/api)。

## 局限

X 页面改版可能导致漏判；模型返回前内容会短暂显示。仅支持文字，未做图片 OCR、视频识别或完整对话上下文分析。模型可能误判广告，也无法可靠鉴定 AI 作者身份。`jev-latest` 更新后表现可能变化。

**22 项模拟测试通过**，覆盖 DOM 节点复用、类别切换、缓存、限流、失败时保留内容和恢复原文等逻辑。这不代表真实页面兼容性或模型准确率。尚未上架 Chrome Web Store。本项目与 X、TypeSafe 无官方关联。
