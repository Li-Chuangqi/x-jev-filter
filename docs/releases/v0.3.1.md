## 中文

本次发布汇总自 v0.1.5 以来的改动：把手动屏蔽和学习改为可查看、可编辑、可撤销的规则。

### 新增与改进

- **手动屏蔽**：推文和回复的分享按钮左侧新增划线眼睛按钮，鼠标悬停时显示。菜单保留“屏蔽并学习相似内容”和“屏蔽账号”，修正详情页对齐。
- **显性规则管理**：支持账号、内容和 Jev 语义规则；可编辑名称、匹配范围、关键词、域名、全部/任一条件及例外，也可启用/停用、删除、查找和 JSON 导入导出。
- **先预览再应用**：“屏蔽并学习”先折叠当前内容，再打开本地提取的条件草稿；只有保存后才用于后续内容。短评论需要填写明确条件，不自动扩大屏蔽范围。
- **规则与样本分离**：保存的规则不再因达到 100 条而被淘汰。独立来源样本最多 100 条，去重后按最旧顺序淘汰；删除样本不删除规则。旧记录自动迁移，折叠提示显示命中的规则名称。
- **可选每日限额**：“限制每日 API 请求量”移入“连接 Jev → 高级设置”。关闭后仍保留用量统计、每分钟限流和错误冷却；升级保留已有上限。
- **设置整理**：“显示「清流已折叠」提示”移到广告类别中，位于“系统广告”和“疑似 AI 创作内容”下方；说明其适用于所有已屏蔽内容。

### 安装与升级

下载下方 **x-jev-filter-0.3.1.zip** 并解压。在 `chrome://extensions` 开启开发者模式，加载包含 `manifest.json` 的文件夹。升级时将文件覆盖到原来的扩展目录，点击重新加载，再刷新 X 和设置页；为保留原有设置，请使用原扩展目录。

导入规则默认停用，检查后再启用。系统广告和疑似 AI 创作默认关闭。Jev 语义规则需开启 Jev 总开关及“用 Jev 执行语义规则”；已有用户的开关意图会保留。

### 数据与验证

规则及来源样本保存在本机。开启 Jev 语义规则后，会发送当前文字、昵称、适用的规则描述与例外，以及最多 5 条相关来源样本文字和昵称至 TypeSafe。规则导出可能包含账号、条件和模板文字；不包含独立样本记录或 API 密钥。

**39 项模拟测试、JavaScript 语法检查、安装包逐文件校验通过**；已检查模拟界面的浅色、深色和窄窗口渲染。尚未完成真实 X 页面和 Jev API 的完整验收及准确率评测。

## English

This release combines all changes since v0.1.5, making manual blocking and learning explicit, editable and reversible.

### Changes

- **Manual blocking:** a crossed-eye action appears on hover to the left of Share on posts and replies. The compact menu offers “Block and learn similar content” and “Block account”, with corrected detail-page alignment.
- **Rule management:** account, local content and Jev semantic rules support editable names, scopes, keywords, domains, AND/OR conditions and exceptions, plus enable/disable, deletion, search and JSON import/export.
- **Preview before applying:** learning immediately collapses the current post and opens a locally extracted draft. Only saved rules affect future content. Short replies require explicit conditions rather than automatic generalization.
- **Separate rule and sample storage:** saved rules are never evicted at 100 entries. Only independent source samples have a 100-entry, deduplicated, oldest-first limit. Removing a sample keeps its rules. Existing records migrate automatically, and placeholders identify the matched rule.
- **Optional daily cap:** “Limit daily API requests” is under Connect Jev → Advanced settings. Disabling it retains usage statistics, per-minute limits and error cooldowns. Existing caps are preserved on upgrade.
- **Settings layout:** the collapsed-content placeholder toggle now appears below platform ads and suspected AI-written content, with clarified coverage of all blocked content.

### Install and update

Download **x-jev-filter-0.3.1.zip**, extract it, enable Developer mode at `chrome://extensions`, and load the folder containing `manifest.json`. To update, replace the files in the existing extension directory, reload the extension, then refresh X and settings. Keep the original directory to preserve the existing installation.

Imported rules start disabled for review. Platform ads and suspected AI-written content are off by default. Semantic rules require both Jev processing and the semantic-rule switch; existing user preferences are preserved.

### Data and validation

Rules and source samples are stored locally. Opt-in semantic processing sends current text/display names, applicable descriptions/exceptions, and up to five related text/name samples to TypeSafe. Exports may contain account handles, conditions and templates, but exclude independent source records and API keys.

**39 simulated tests, JavaScript syntax checks and per-file ZIP verification passed.** Mock UI rendering was checked in light, dark and narrow layouts. Full live-X and real-Jev validation, including accuracy evaluation, remains outstanding.
