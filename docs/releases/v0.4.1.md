# v0.4.1 — 一键折叠与个人同步 / One-click blocking and personal sync

本次公开发布汇总 v0.3.1 之后的更新：

- 点击分享按钮左侧的屏蔽图标，直接折叠并学习，不再弹出选择菜单或确认窗口。
- 简化规则编辑界面，修复悬停入口显示，已保存的 API Key 显示为密码圆点。
- 新增个人规则同步：同一 Chrome 账号跨设备合并规则及启停、例外、删除，默认关闭。支持离线修改、冲突备份和容量错误提示。
- 新增独立的 Jev 密钥加密同步，默认关闭。以下为使用与升级说明。

This public release includes changes since v0.3.1: one-click blocking without menus, a simpler rule editor, corrected hover visibility, masked saved keys, opt-in personal rule sync with offline edits/conflict backups/quota feedback, and separate encrypted Jev key sync.

新增独立的“同步 Jev API 密钥”开关，默认关闭。先在第一台设备保存 Key，设置至少 12 字符的独立同步口令；新设备填写一次相同口令即可解锁，无需重新粘贴 Key。设备保留不可导出的解锁 CryptoKey，口令不保存也不上传。

Adds a separate, default-off encrypted Jev API key sync switch. Save the key on the first device and set an independent passphrase of at least 12 characters. New devices unlock once with that passphrase. The passphrase is never stored or uploaded; a non-exportable CryptoKey stays on each unlocked device.

关闭开关移除本设备解锁凭据，但当前会话仍可使用 Key；“清除密钥”还会关闭本设备密钥同步，防止自动恢复。两者不删除 Chrome 同步存储中的密文或其他设备的密钥。保存新 Key 时自动更新密文，写入失败保留原 Key 并提示。

Disabling removes the device unlock credential while retaining the current session key. Clearing the key also disables device key sync to prevent restoration. Neither removes cloud ciphertext or keys on other devices. Replacement keys update the encrypted record; failed writes preserve the previous key.

v0.4.0 用户替换文件并重新加载即可，扩展 ID 不变。v0.3.x 用户仍需先导出规则再迁移。

From v0.4.0 replace files and reload; extension ID is unchanged. Export rules before upgrading from v0.3.x.

56 项模拟测试通过；Chrome 中验证真实 Web Crypto / IndexedDB 凭据持久化、空会话恢复、清除不回填。真实 Chrome 账号下跨设备网络同步仍需验收。

56 simulated tests pass. Real Chrome Web Crypto / IndexedDB persistence, session restoration and clearing behavior were checked with mocked sync transport. Real-account cross-device delivery remains unverified.

## 安装包 / Assets

下载 `x-jev-filter-0.4.1.zip`，解压后在 Chrome 扩展管理页开启开发者模式，加载包含 `manifest.json` 的目录。`SHA256SUMS-v0.4.1.txt` 用于校验安装包。GitHub 自动生成的 Source code 压缩包需要选择其中的 `extension/` 目录。

Download and extract `x-jev-filter-0.4.1.zip`; enable Developer mode and load its manifest directory. Use `SHA256SUMS-v0.4.1.txt` to verify the ZIP. For GitHub source archives, load the nested `extension/` directory.
