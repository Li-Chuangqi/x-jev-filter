# v0.4.0 — 个人跨设备规则同步 / Personal rule sync

通过同一 Chrome 账号同步清流规则，默认关闭，在每台设备的设置页单独开启。保留离线使用和一键折叠；新增、编辑、启停和删除自动同步。仅同步规则，不上传独立来源样本、API 密钥、全局白名单、过滤设置或用量。

Sync rules through the same Chrome account with per-device opt-in. Offline filtering and one-click blocking remain available. Source samples, API keys, global allowlists, filter settings and usage stay local.

## 升级 / Upgrade

升级前在旧版导出规则。v0.4.0 使用固定扩展 ID `hbcocdmomlljjgphneaeefolcondcnll`，Chrome 可能将其视为新插件。停用旧版后安装新版，导入规则（默认停用，检查后启用），重新填写必要设置。其他设备安装同一版本并开启同步，无需重复导入。

Export rules before upgrading: the new fixed extension ID can create a separate installation. Disable the old extension, import and enable your rules, and reconfigure preferences. On other devices install this version and opt in without re-importing duplicates.

## 边界 / Limits

Chrome 同步存储上限：100 KB 总量、8 KB 单项、512 项（含删除标记）。超限显示错误并保留本地数据。关闭同步不删除云端规则。并发编辑采用较新版本时间，最多保留 20 条被替换的本机规则备份。浏览器同步状态不能由插件确认，界面仅报告 Chrome 同步存储的合并结果。

Chrome sync storage quotas: 100 KB total, 8 KB per item, 512 items including deletion markers. Quota errors retain local data. Disabling sync does not erase cloud rules. Newer version timestamps win; up to 20 replaced local rules are retained as exportable backups. The extension cannot confirm cloud delivery.

## 验证 / Validation

50 项自动化模拟测试通过，包含双设备合并、离线删除、并发修改、重试、容量限制、来源数据隔离、设置交互与消息权限。Chrome 中以模拟存储执行真实同步模块，检查设置页开启、立即同步、关闭、窄屏布局与页面错误。

50 automated simulated tests pass. Chrome settings smoke checks use the real sync module with mocked storage. Actual transfer between two signed-in Chrome devices remains unverified.
