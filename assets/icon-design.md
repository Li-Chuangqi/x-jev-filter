# Icon design

Created with the built-in image_gen tool. Original generation followed by a background cleanup edit. Master: assets/icon-source.png. Production sizes exported using macOS sips.

## Generation prompt

Use case: logo-brand. Create one finished square Chrome browser extension icon for an existing X feed cleaning extension. Primary request: a broom sweeping a huge X silhouette lying flat on the ground. Simple bold vector-like illustration, not a scene or a mockup. The large near-black X lies on a subtly foreshortened ground plane and occupies most of the icon. A single clearly recognizable broom, with chunky warm straw bristles and a dark green handle, sweeps diagonally across the X; the bristles visibly contact its edge, brushing away a small portion into 2–3 bold fragments. Keep most of the X intact and instantly recognizable. Existing app accent is forest green. Use a pale mint rounded-square tile, dark charcoal X, forest green broom handle, warm golden bristles. Strong silhouette, thick shapes, very few details, crisp edges, restrained depth, excellent legibility at 32px. Centered icon filling roughly 85% of square, comfortable edge padding. No words, no lettering besides the large X symbol, no border labels, no watermark, no hands or person, no extra objects, no presentation sheet. Generate a single 1024x1024 icon.

## Final edit prompt

Edit this icon. Preserve the broom sweeping the giant dark X lying flat on the ground, the composition, golden bristles, green handle and few swept fragments. Replace ALL of the background with a perfectly flat, fully opaque pale mint #E8F5EC. Remove the large blurry dark patch in the upper left entirely. Remove every fuzzy, noisy, grainy or semi-transparent area. Make the outer canvas a simple fully opaque square with this same solid mint color extending to all four corners; no rounded-square tile or transparency. Keep the icon subjects crisp and high contrast. No text, no watermark. Finished clean 1024x1024 extension icon.
